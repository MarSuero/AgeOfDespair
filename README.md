# Age of Despair

Monster Hunter Wilds Mod：让“怪物的粪”变成真正可以吃的狩猎道具。

## 当前效果

使用“怪物的粪”后：

- 立即回满生命值
- 获得中毒效果
- 获得恶臭效果
- 自带“满足感 3”技能效果
- “道具使用强化”可以延长中毒和恶臭的持续时间

## 广域化

这个道具支持广域化，可以影响附近队友。

为了避免在救援任务里被别人恶意利用，接收效果的玩家也必须安装本 Mod。没有安装 Mod 的玩家不会被强行写入效果。

## 安装

从 [Releases](https://github.com/MarSuero/AgeOfDespair/releases) 下载最新压缩包，把其中的 `reframework` 文件夹复制到 Monster Hunter Wilds 游戏目录并合并。

需要安装的文件：

```text
reframework/autorun/age_of_despair.lua
reframework/plugins/AgeOfDespair_Action.dll
reframework/plugins/AgeOfDespair_Availability.dll
```

## 卸载

删除上面列出的三个文件即可。本 Mod 不修改 PAK、存档或原始游戏文件。
