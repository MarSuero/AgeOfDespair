更新时间：2026-10-02  
项目目录：`D:\mhws-eatshit`

游戏：Monster Hunter Wilds Steam PC `1.42.0.2`  
REFramework：`v1.5.9.1`

## 一、当前目标

公共物品 ID `98` 是「怪物的粪」。当前已能让它出现在「狩猎道具」栏，并播放用户接受的喝药样动作。

后续目标是：物品 98 使用完成后，给玩家施加桃毛兽王同款的玩家侧「恶臭」异常。该状态会在一段时间内阻止吃喝物品，并由除臭球原生解除。广域化暂未开始。

## 二、已经确认

- 公共 ID `98` -> 运行时 ItemData 行 `_ItemId=99`
- `canUseItem(98)` 返回 `true`
- `_TextType=1`、`_Window=true`、`_Eatable=true` 可以把 98 移入「狩猎道具」
- `notUseItem(98)` 可以通过原生 REFramework hook 绕过
- 当前用户接受现有喝药样动作，不要擅自改成 `cEatMeat`
- BTable 映射：
  - 类型 `1` -> `cUseDrinkItem`
  - 类型 `2` -> `cEatMeat`
- PAK 候选实际加载过，但仅改 ItemData 仍不能触发正常使用
- `set_UsedItemID(98)` 不会触发，因此不能作为恶臭触发点
- 已验证玩家恶臭链：

```text
HunterCharacter.get_HunterStatus()
  -> cHunterStatus.get_BadConditions()
  -> cHunterBadConditions._Stench
  -> cStench.requestActivate()
```

- 清除链是游戏原生的：
  - `cStench.cure()`
  - `checkAndCureConditions(...)`
  - `deactivateAllConditions()`
  - `onWaterWash()`
- `BAD_CONDITION.STENCH` 和 `BAD_CONDITION_Fixed.STENCH` 存在
- 可用物品限制相关字符串包括 `checkSkillStench`

## 三、最后验证结果

已验证成功：

- 98 出现在「狩猎道具」
- `notUseItem(98)` 被绕过
- 98 播放喝药样动作

未验证成功：

- `set_UsedItemID(98)` 没有调用
- 通过 `set_UsedItemID` 激活恶臭失败
- 通过 `cHunterSubActionBase.isSubActionEnd` 过滤 `cUseDrinkItem` 的候选也未激活恶臭
- 最后一次动作结束候选的日志只看到 `notUseItem(98)` 返回 `false`，没有看到动作结束命中或 `stench activated`，因此不能把 `isSubActionEnd` 当成已验证成功边界

因此下一步应继续找真实的 item-success / action-success 边界，不要继续修改 ItemData，也不要继续重复旧探针。

## 四、当前部署状态

当前游戏目录在交接前检查到以下活动文件：

```text
reframework/autorun/mhws_eatshit_item98_usable_bridge.lua
reframework/plugins/mhws_eatshit_item98_notuse_bridge.dll
reframework/plugins/mhws_eatshit_item98_eat_action_bridge.dll
```

这三件组成当前用户认可的“可用物品 98”版本。没有部署恶臭桥、元数据桥或探针。接手人开始新实验前，应先关闭游戏并按需回滚这三件文件。

## 五、重要路径

- `analysis/`：所有静态分析、运行时结果和失败记录
- `docs/`：技术调查、运行记录、旧探针日志
- `scripts/`：Lua 探针和功能候选，绝大多数已禁用
- `native_bridge/`：REFramework 原生插件源码、构建脚本和 DLL
- `extracted/base/`：只读提取的基础 PAK 数据
- `extracted/patch_014/`：只读提取的 patch-014 数据
- `extracted/stench_base/`：怪物异常/粪便 shell 相关只读提取
- `candidates/`：失败 PAK 候选和打包目录
- `backups/`：旧候选和禁用脚本
- `release/MHWS_Eatshit_Usable_0.1.0.zip`：给普通玩家安装的可用版本
- `tools/rsz_local/`：RSZ 解析器、检查脚本和 Wilds 类型 dump
- `tools/REE.PAK.Tool/`：本地 PAK 解包/打包工具
- `tools/REFramework-sdk/`：官方 REFramework 原生插件 SDK checkout

## 六、接手人硬规则

- 先读本文件、`HANDOFF_NEW_CHAT.md`、`PROJECT_STATUS.md`、`DEPLOYMENT_STATUS.md`、`CHECKSUMS.txt`
- 不再猜 ItemData 字段
- 不再重复已经完成的 gate、分类和元数据读取

- 不要修改原始 PAK 或存档

- 恶臭目标固定为玩家侧 `app.HunterBadConditions.cStench`
- 每次改动都要测试、同步校验清单并单独提交 Git commit
