# 交接包清单

本包是给下一位开发者的完整研究交接包，不是普通玩家安装包。

## 包含

- 中文交接说明
- `HANDOFF_NEW_CHAT.md`
- `PROJECT_STATUS.md`
- `DEPLOYMENT_STATUS.md`
- `CHECKSUMS.txt`
- 全部静态分析和运行结果
- 全部 Lua 探针、禁用探针和功能候选
- 全部原生 REFramework bridge 源码、构建脚本和已编译 DLL
- 只读提取的 RSZ/UserData 数据
- PAK 工具、RSZ 解析器和 REFramework SDK
- 已发布的普通玩家安装包

## 不包含

- Python 虚拟环境
- Windows/.NET 安装器和安装日志
- Git 内部目录
- 游戏安装目录副本
- 存档、原始 PAK 和账号凭据

## 交接时的重要事实

- 当前用户认可的是 98 的喝药样动作
- 玩家恶臭尚未成功接入
- 所有实验桥都应保持未部署，除非下一位开发者明确安排单次验证
